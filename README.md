# Technical Efficiency and Enteric Methane Emission Intensity in a Transition-Economy Dairy Sector: A Stochastic Frontier Analysis from Azerbaijan

Reproducibility package for a study examining whether district-level
technical efficiency in Azerbaijan's dairy sector is associated with
enteric methane emission intensity, once both measures' shared
mechanical dependence on milk yield is properly accounted for.

**Author:** Halil Tosun, ADA University, School of Agricultural and
Food Sciences, Department of Animal Science, Baku, Azerbaijan.
ORCID: [0000-0001-5117-0390](https://orcid.org/0000-0001-5117-0390)

## What This Repository Reproduces

Running the pipeline end-to-end reproduces every table and figure
reported in the manuscript and its Supporting Information:

| Output | Description | Script |
|---|---|---|
| Table 1 | Descriptive statistics | `05_descriptive_stats.py` |
| Table 2 | Stochastic frontier estimation results | `02_sfa_frontier_estimation.py` |
| Table 3 | Second-stage regression | `06_second_stage_regression.py` |
| Table 4 | Robustness checks | `07_robustness.py` |
| Table S1 | Variance-inflation factors | `03_diagnostics.py` |
| Table S3 | Frontier re-estimation excl. post-conflict districts | `03_diagnostics.py` |
| Table S4 | Labor-augmented frontier | `03_diagnostics.py` |
| Table S5 | Leave-one-out / random-exclusion test | `08_leave_one_out_test.py` |
| Figure 1 | Technical efficiency trend by year | `09_figure1_te_trend.py` |
| Figure 2 | District ranking | `10_figure2_district_ranking.py` |
| Figure 3 | Raw vs. yield-netted association | `11_figure3_yield_confound.py` |

Every script contains internal `assert` statements checking its output
against the corresponding manuscript/Supporting Information value; the
pipeline stops immediately if any value fails to reproduce.

## Quick Start

```bash
conda env create -f environment.yml
conda activate azerbaijan-dairy-te-methane-repro
cd code
python run_all.py
```

See `docs/Replication_Guide.md` for step-by-step instructions, how to
run individual scripts, and how to adapt this pipeline to a different
setting.

## Data Source

All raw data are publicly available official statistics from the State
Statistical Committee of the Republic of Azerbaijan (SSC RA), 2025,
*Agriculture, Forestry and Fishery -- Statistical Yearbook Data*
(https://www.stat.gov.az/source/agriculture/en/), and IPCC (2006),
*2006 IPCC Guidelines for National Greenhouse Gas Inventories*, Volume
4, Chapter 10. No proprietary or restricted-access data are used. Full
provenance for every variable is documented in `docs/DATA_DESCRIPTION.md`.

## Transparency Note

This package documents, rather than silently absorbs, every
substantive correction identified during its preparation -- including
a stale set of correlation statistics in an earlier draft of the
manuscript's Results section that predated a later cattle/buffalo
species-denominator correction, and two implementation bugs in the
diagnostic scripts (an incorrect labor-variable form in the
variance-inflation-factor check, and an unreliable optimizer
convergence flag). See `docs/REPRODUCIBILITY_CHECKLIST.md` for full
detail on each. The manuscript accompanying this repository reflects
all of these corrections.

## Independence from Related Work

Ten districts examined in this study correspond to territories
reintegrated following the 2020 ceasefire. This repository is
self-contained and does not import from, or depend on, any other
project's code or data; all district-level statistics used here are
independently harmonized from their original SSC RA source tables by
`code/01_data_preparation.py`.
